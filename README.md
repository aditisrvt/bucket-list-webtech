# Bucket List

A bucket list web application that allows users to add their dreams, organize them into categories, track completed goals and monitor their overall progress.

## Features

- Add and delete dreams.
- Organize dreams into categories.
- Mark dreams as completed.
- Filter dreams by category.
- Track total and completed dreams.
- Save dreams using browser Local Storage.

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

1. Clone the repository:
   ```bash
   git clone https://github.com/aditisrvt/bucket-list-webtech.git
   ```
2. Open the project folder.
3. Open `index.html` in a web browser.
